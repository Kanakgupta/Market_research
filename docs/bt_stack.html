Platform Bluetooth Stack

Platform Vendor SDK Bluetooth 5.4 / LE Audio Proprietary (vendor SDK)

Vendor-integrated dual-mode stack tuned to Platform silicon.

Full dual-mode (BR/EDR + LE) host+controller shipped as part of the Platform ModusToolbox SDK. Tightly co-designed with the radio for low-power tuning, qualified per release, with vendor lifecycle support and LE Audio on the newest parts. It is a turnkey, time-to-market choice inside the Platform ecosystem.

Nordic SoftDevice / nRF Connect SDK

Nordic Semiconductor Vendor SDK Bluetooth 5.4 / LE Audio Proprietary SoftDevice + Zephyr-based SDK

Precompiled LE stack ('SoftDevice') plus a Zephyr-based SDK; the default for many BLE products.

Nordic ships two paths: the classic binary SoftDevice controller (S1xx) and the newer nRF Connect SDK built on Zephyr with Nordic's SoftDevice Controller. LE-only (no Classic), extremely well documented, huge developer base, and among the earliest to ship LE Audio and Channel Sounding on nRF54 parts.

  • Classic-only accessories (car kits, legacy game controllers) need a different chip/stack.
