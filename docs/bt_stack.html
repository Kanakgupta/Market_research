Bluetooth Core release history & cadence
  • Bluetooth Core 6.3 (April 2026) — Latest Core release -- continues the 6.x wave (ranging/Channel Sounding refinements and incremental LE enhancements). Confirm the exact feature list against the published spec.
  • Bluetooth Core 6.2 (October 2025) — Incremental Core enhancements building on 6.0/6.1.
  • Bluetooth Core 6.1 (April 2025) — Privacy and controller refinements (e.g. randomized RPA update timing) plus link-layer enhancements.
  • Bluetooth Core 6.0 (2024) — Channel Sounding (secure phase/RTT ranging), decision-based advertising filtering, monitoring advertisers, LL extended feature set.
  • Bluetooth Core 5.4 (2023) — Periodic Advertising with Responses (PAwR), Encrypted Advertising Data, advertising coding selection.
  • Bluetooth Core 5.3 (2021) — Connection Subrating, periodic advertising enhancements, channel classification.
  • Bluetooth Core 5.2 (2020) — LE Audio foundations: Isochronous Channels, LE Power Control, Enhanced ATT (EATT).

The Bluetooth SIG publishes Core specifications roughly every April and October. To keep this page current, add the new release to BT_SPEC_RELEASES in bt_stacks_data.py — the hero label, every “Missing vs…” header and this banner update automatically.

Infineon AIROC Bluetooth Stack

Infineon AIROC Vendor SDK Bluetooth 5.4 / LE Audio Proprietary (vendor SDK)

Vendor-integrated dual-mode stack tuned to Infineon AIROC silicon.

Full dual-mode (BR/EDR + LE) host+controller shipped as part of the Infineon AIROC ModusToolbox SDK. Tightly co-designed with the radio for low-power tuning, qualified per release, with vendor lifecycle support and LE Audio on the newest parts. It is a turnkey, time-to-market choice inside the Infineon AIROC ecosystem.

💾 Representative Silicon & Modules

AIROC CYW20829 (BLE MCU, Bluetooth 5.4 + Channel Sounding), CYW20819/20820 (dual-mode BT/BLE), CYW5557x (Wi-Fi 6E/7 + Bluetooth combo), CYW43439/43012 (Wi-Fi 4 + BT combo), CYW89820 (automotive BT), PSoC 62/63 + combo designs, plus AIROC CYBT-/CYW9-series certified modules.

🔧 Footprint & Integration

Host + controller shipped together in ModusToolbox. Runs on Arm Cortex-M (CYW20829 M33, PSoC 6 M4/M0+) and as an HCI controller under Linux/RTOS hosts; FreeRTOS + ThreadX supported. On-chip stack fits typical BLE-MCU budgets (order of hundreds of KB flash).

Nordic SoftDevice / nRF Connect SDK

Nordic Semiconductor Vendor SDK Bluetooth 5.4 / LE Audio Proprietary SoftDevice + Zephyr-based SDK

Precompiled LE stack ('SoftDevice') plus a Zephyr-based SDK; the default for many BLE products.

Nordic ships two paths: the classic binary SoftDevice controller (S1xx) and the newer nRF Connect SDK built on Zephyr with Nordic's SoftDevice Controller. LE-only (no Classic), extremely well documented, huge developer base, and among the earliest to ship LE Audio and Channel Sounding on nRF54 parts.

💾 Representative Silicon & Modules

nRF52 series (nRF52840/52833/52811/52832), nRF53 dual-core (nRF5340), nRF54 series (nRF54L15 / nRF54H20 -- Bluetooth 6.0 incl. Channel Sounding), nRF21540 FEM for range; nRF7002 companion IC for Wi-Fi.

🔧 Footprint & Integration

LE-only. SoftDevice = precompiled controller binary (S112/S113/S132/S140) on nRF52; nRF Connect SDK (Zephyr) with SoftDevice Controller on nRF53/54. Cortex-M; hundreds of KB flash; Zephyr RTOS.
